# Seek Fragment Capture

Отдельное Chromium-расширение. Оно не зависит от Cat Catch и не внедряет панель поверх сайта.

## Как работает

1. Popup находит HTML5-плеер, в том числе во вложенных frame.
2. Content script последовательно меняет `currentTime` от начала к концу.
3. Service worker через `chrome.webRequest` собирает реальные запросы плеера:
   - HLS: `m3u8`, `ts`, `m4s`, ключи и init-сегменты;
   - DASH manifest и сегменты сохраняются как кандидаты;
   - progressive MP4/WebM с `Range`;
   - URL без расширения с медиа MIME или крупным `application/octet-stream`.
4. После прохода открывается отдельная страница расширения.
5. Сборщик сначала пробует HLS manifest, затем полный progressive-файл, затем raw-последовательность перехваченных сегментов.
6. Файл пишется в OPFS потоком, поэтому целиком в оперативной памяти не хранится.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `standalone-extension`.

## Использование

1. Откройте страницу и запустите видео хотя бы один раз.
2. Откройте popup расширения.
3. Выберите плеер и диапазон.
4. Оставьте шаг перемотки 8 секунд для обычного HLS. Если сегменты короче — уменьшите шаг.
5. Нажмите «Запустить» и не закрывайте исходную вкладку.
6. После прохода автоматически откроется сборщик.

## Ограничения

- DRM/EME не расшифровывается.
- Для HLS с отдельной аудиодорожкой расширение сохраняет video и audio отдельными файлами; mux пока не выполняется.
- DASH с отдельными audio/video Representation пока попадает в raw fallback и может потребовать внешний mux.
- Некоторые сайты изолируют дочерний frame или запрещают программную перемотку.
